Pet Shop

Tech Stack
사용된 기술
JAVA
JSP Servlet
HTML CSS3 Bootstrap4.0
MySQL

주요기능
상품 목록 및 상세 보기 : 부트 스트랩 카드를 활용한 상품전시
장바구니 시스템: 세션을 활용한 실시간 장바구니 추가,삭제 및 수량 관리
보안 주문 프로세스: 로그인 여부를 확인하여 비로그인 시주문을 제한하는 체크아웃 로직 적용

프로젝트 구조
src/dto : 상품 정보 관리를 위한 javabean (Prduct.java)
webapp : jsp 파일 및 정적 리소스 (CSS , IMAGES)
webapp/mnu.jsp : 공용 해더 네비게이션바
webapp/cart.jsp : 세션 기반 장바구니 페이지

구현상세
세션기반 상태 관리 :  HttpSession을 활용하여 사용자가 브라우저를 닫기 전까지 장바구니 상태가 유지되도록 구현 상품의 추가/삭제/수량이
실시간으로 반영되도록 로직을 작성했습니다.

쿠키를 활용한 배송 정보 전달: 주문 과정에서 입력한 배송 정보를 쿠키에 저장하고 최종페이지에 이를 디코딩하여 출력함으로 페이지간
데이터 전달 효율성을 높였습니다.

보안로직 : cart.jsp에서 결재단계로 넘어갈때 세션의 sessionId존재 여부를 체크하여 비로그인 상태면 반드시 로그인 페이지로
돌아가도록 걸치는 로직을 구현했습니다.

데이터 무결성 검사: 장바구니가 비어 있는 상태에서는 주문하기 버튼이 비활성화 되어있도록 설정했습니다.

MY SQL
Product Table: 상품 아이디,이름,가격,상세설명,제조사,카테고리,재고 수량,이미지 등의 필드를 구성해 체계적인 상품관리가 가능하도록 설계
Member table: 사용자 인증을 위한 아이디,비밀번호,성함,연락처,이메일 정보를 저장합니다.
